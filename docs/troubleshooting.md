# Troubleshooting

[简体中文](troubleshooting.zh-CN.md)

Where to look, in this order:

1. **The PR comment.** When the engine recognizes the cause, the comment names it (the reason codes below)
   and says how to fix it.
2. **The workflow run.** On the PR's Checks tab, open the deploy job: the step of the action that failed
   shows the error, and the **Diagnostics** step after it prints the environment's state.
3. **On the host**, `tailnet-preview doctor <env>` (`main`, `pr-<number>` or `br-<branch>`) prints the same
   state at any time: containers, the Tailscale node or the shared ingress, whether HTTPS certificates are
   available, whether each upstream answers, and recent logs.

## Failures the engine recognizes

| Reason          | Symptom                                                                                                                                                                                                                          | Cause                                                                                                                                                                                         | Fix                                                                                                                                                                                                                                                                                                                                                    |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `config`        | Deploy fails immediately                                                                                                                                                                                                         | Invalid `.tailnet-preview/` (unknown key, missing file, bad `HTTP`)                                                                                                                           | Fix what the message names ([design.md section 5](design.md#5-project-configuration))                                                                                                                                                                                                                                                                  |
| `registry`      | `connection reset by peer` while pulling, after retries                                                                                                                                                                          | The host's link to Docker Hub                                                                                                                                                                 | Proxy or registry mirror for the Docker daemon ([host-setup.md](host-setup.md#2-the-machine-once)), check with `docker pull`                                                                                                                                                                                                                           |
| `build`         | Image build fails                                                                                                                                                                                                                | Base image pull (as above) or a compile error                                                                                                                                                 | Read the build step                                                                                                                                                                                                                                                                                                                                    |
| `ts_secret`     | `no TS_OAUTH_SECRET`                                                                                                                                                                                                             | Neither the host configuration nor a repository secret                                                                                                                                        | [host-setup.md](host-setup.md#2-the-machine-once) step 2.4                                                                                                                                                                                                                                                                                             |
| `ts_login`      | Sidecar did not log in within two minutes                                                                                                                                                                                        | OAuth secret revoked or expired, `tag:preview` missing from `tagOwners`                                                                                                                       | `docker logs <project>-<env>-ts-1`                                                                                                                                                                                                                                                                                                                     |
| `https`         | Deploy "fails" although everything runs; browsers report a reset TLS handshake; `tailscale cert` says `does not support getting TLS certs`                                                                                       | HTTPS certificates are not enabled for the tailnet                                                                                                                                            | Admin console → DNS → enable MagicDNS and HTTPS, then `tailnet-preview compose <env> restart ts`. The environment was kept; the next deploy upgrades it                                                                                                                                                                                                |
| `cert` (notice) | The PR comment says "ready" with "HTTPS certificate pending"; browsers cannot connect (`curl` reports a refused connection); the reason says `NXDOMAIN`, `Incorrect TXT record`, `SetDNS ... deadline exceeded` or `rateLimited` | Let's Encrypt did not issue the node's certificate during the deploy: Tailscale's DNS validation record had not reached public DNS yet, or five validations of the name failed within an hour | Wait: the sidecar requests it again after 6, 26 and 71 minutes, then hourly for a day, at least 6 minutes after a failure and after any rate limit has lifted (`tailnet-preview doctor <env>` shows the attempts), and serves HTTPS once it has the certificate. These are problems of Tailscale's certificate service, not of the host or the project |
| `fork`          | Copying the baseline's data failed                                                                                                                                                                                               | A `DATA_VOLUMES` entry is not a volume of `compose.yaml`, or the baseline is broken                                                                                                           | Fix `DATA_VOLUMES`; `tailnet-preview doctor main`                                                                                                                                                                                                                                                                                                      |
| `migrate`       | The migrate task fails                                                                                                                                                                                                           | A broken migration, or a migration edited after it ran in this environment                                                                                                                    | Fix it; for an edited migration, `tailnet-preview reset pr-<n>`                                                                                                                                                                                                                                                                                        |
| `seed`          | The seed task fails                                                                                                                                                                                                              | The seed command                                                                                                                                                                              | Read its output                                                                                                                                                                                                                                                                                                                                        |
| `health`        | `HEALTH_PATH` did not answer within two minutes                                                                                                                                                                                  | The application fails at startup, or `HTTP`/`HEALTH_PATH` point to the wrong place                                                                                                            | Service logs are printed in the run                                                                                                                                                                                                                                                                                                                    |

## Other symptoms

| Symptom                                                         | Cause                                                                                                                                                  | Fix                                                                                                                                                    |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| The PR says ready, but the browser cannot find the site         | The device you browse from does not use Tailscale DNS ("Use Tailscale DNS" off, or `--accept-dns=false`). The host cannot see this                     | Turn it on in that device's Tailscale client; `tailscale ping <project>-<env>` should answer                                                           |
| The browser cannot connect at all (timeout)                     | The tailnet policy does not let your device reach `tag:preview` on that port                                                                           | [host-setup.md](host-setup.md#1-the-tailnet-once) step 2                                                                                               |
| The job waits for a runner forever                              | No runner labelled `preview` serves this repository, or it is offline                                                                                  | Settings → Actions → Runners; or unset `PREVIEW_ENABLED`                                                                                               |
| "No preview environment was created"                            | `MAX_ENVS` PR environments exist, or available memory is below `MIN_FREE_MB`                                                                           | Close PRs you do not need, push again                                                                                                                  |
| Shared ingress: the name does not resolve                       | The tailnet has no split DNS entry for `TP_INGRESS_DOMAIN`, the policy does not allow port 53 to the ingress, or the device does not use Tailscale DNS | Host setup section 4; `dig <name> @<ingress address>` from a tailnet device                                                                            |
| Shared ingress: certificate warning in the browser              | The wildcard certificate is not issued yet (Traefik serves its own)                                                                                    | `tailnet-preview doctor <env>` shows Traefik's ACME messages; usually the DNS token's permissions or `TP_INGRESS_ACME_EMAIL`                           |
| The address ends in `-1` (`myapp-pr-42-1.…`); notice `hostname` | Another device in the tailnet has the environment's name, usually a node of an earlier environment that never logged out                               | In the admin console (Machines), remove the old device and rename this one to `<project>-<env>`, then push again; the next deploy picks up the address |
| The first PR was not copied from a baseline                     | Expected: the default branch does not use tailnet-preview yet                                                                                          | Merge it; the next PRs are copied                                                                                                                      |
| A PR environment has stale data after editing an old migration  | Migrations only move forward                                                                                                                           | `tailnet-preview reset pr-<n>`                                                                                                                         |
| Environments of closed PRs remain                               | The host was offline when the PR closed                                                                                                                | The nightly job removes them; or `tailnet-preview prune <open PR numbers>`                                                                             |
